How Cyclic Redundancy Check (CRC) Works

1 Appending Zeros

Given a generator polynomial $G$ of length $n$ (degree $k = n - 1$), we append $k$ zeros to the original message bitstream $D$. This prepares space for the $k$-bit CRC checksum.

2 Modulo-2 Division (XOR)

Modulo-2 arithmetic uses bitwise XOR operations instead of standard subtraction. Whenever the leading bit is 1, we XOR the window with the generator polynomial. If it's 0, we shift.

3 Error Verification

The remainder of length $k$ is appended to $D$ to form the codeword. At the receiver, performing modulo-2 division on the codeword using $G$ yields a remainder of all zeros if no bits were corrupted!
